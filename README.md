# music-bot
@scmusicsavebot — a Telegram bot for downloading tracks and playlists from SoundCloud. Built with aiogram 3 and yt-dlp, featuring inline search, download history, premium subscription via Tribute, and anonymized user data storage.

This bot is intended for personal use only. Downloading copyrighted content may violate SoundCloud's Terms of Service and applicable copyright laws. Use at your own responsibility.
